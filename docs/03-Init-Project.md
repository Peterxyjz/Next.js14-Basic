# 03 - Cài đặt dự án

Câu lệnh:

```bash
npx create-next-app@14.1.2
```

## Cấu trúc thư mục dự án Next.js

- .next là folder nó tự tạo ra là code server giống như dist
- public là folder chứa media hình ảnh
- src chưa code chính: app - page.tsx giống như index
- next-env.d.ts: định nghĩa nhưng kiểu dữ liệu đặc biệt
